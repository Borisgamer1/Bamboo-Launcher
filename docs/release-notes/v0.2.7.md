# Bamboo Launcher 0.2.7

Die Startseite ist jetzt der Ort, an dem du wirklich weiterspielst: die letzte
Welt als große Karte, darunter Welten, Server und Profile. Der Launcher startet
die Welt ab Minecraft 1.20 direkt per Quick Play, verbindet Server mit dem
passenden Profil und merkt sich, was zuletzt lief.

## Neu

- **Neue Startseite „Weiterspielen“:** Die letzte Welt steht als große Karte
  oben, darunter folgen Welten, Server und Profile. Die Startseite liegt auf dem
  Theme-Hintergrund statt auf einer schwarzen Fläche.
- **Quick Play für Welten:** Ab Minecraft 1.20 öffnet „Weiter spielen“ die Welt
  direkt. Bei älteren Versionen startet der Launcher wie bisher das Profil.
- **Welten und Server anpinnen:** Favoriten stehen oben und bleiben lokal
  gespeichert. Server merken sich zusätzlich den letzten Beitritt.
- **Server direkt von der Startseite:** Ping, Spielerzahl und das passende Profil
  stehen neben jedem Server. „Beitreten“ startet die Instanz und verbindet;
  das Plus öffnet direkt den Server-Dialog.
- **Hintergrund und Effekte für Preset-Themes:** Hintergrundbild, Partikel und
  Glow lassen sich in Darstellung jetzt einzeln abschalten, ohne auf eigene
  Farben zu wechseln.
- **CurseForge-Key beim Umstieg:** Der Key aus der alten Electron-Fassung wird
  übernommen. Fehlt er in der Mod-Suche, führt „Key hinterlegen“ direkt zu
  Einstellungen → Erweitert.

## Besser

- Die Startseite zeigt relative Spielzeit, Version, Loader und den letzten
  Serverstatus statt einer Sammlung von Links.
- Startende Instanzen zeigen „Startet“ mit Spinner; erst wenn das Spiel läuft,
  wechselt der Knopf auf „Beenden“.
- Angepinnte Profile und Server stehen oben und lassen sich ohne Umweg über die
  jeweilige Ansicht starten.
- Die Bamboo-Marker vor Überschriften sind entfernt. Die Startseite arbeitet mit
  Typografie, Abständen und einer Akzentfarbe statt mit Dekoration.

## Behoben

- Ohne Hintergrundbild zeigte der Start einen falschen Basiston statt der
  Theme-Fläche.
- Helligkeit und Unschärfe wurden bei Preset-Themes ignoriert; beide Regler
  wirken jetzt auch dort.
- Ein Weltname für Quick Play wird vor dem Start geprüft: nur ein direkter
  Ordnername aus `saves/` erreicht das Spiel.

Vollständige Liste: `ui/CHANGELOG.md`.

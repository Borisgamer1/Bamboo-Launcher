# Bamboo Launcher 0.2.9

Der Bamboo Client ist wieder raus, und Resourcepacks kommen endlich im Spiel an.
Der Launcher macht nur noch Instanzen, Mods und Bamboo Cosmetics.

## Behoben

- **Resourcepacks erscheinen im Spiel:** Ein Paket aus dem Store, aus einem
  Modpack oder aus einer eigenen Datei landet in `resourcepacks/` – geladen
  wird aber nur, was in der `options.txt` ausgewählt ist. Diese Auswahl hat der
  Launcher nie geschrieben, deshalb war das Paket im Spiel unsichtbar. Jetzt
  trägt er es beim Installieren ein und beim nächsten Start nach, falls das
  Spiel gerade lief. Pakete für eine andere Pack-Version werden zusätzlich als
  „inkompatibel, aber erlaubt“ markiert, statt still zu verschwinden.
- **Vorhandene Pakete werden einmalig übernommen:** Instanzen, in denen schon
  Pakete lagen, bekommen sie beim nächsten Start einmalig ausgewählt. Danach
  gilt die Auswahl im Spiel: Was dort abgewählt wird, bleibt abgewählt.
- **Slim-Skins werden richtig gerendert:** Die Skin-Variante kam nur aus einer
  lokalen Datei, Mojangs Angabe zum aktiven Skin wurde ignoriert. Ein Slim-Skin
  lief deshalb als Classic-Modell – Arme und Hände saßen falsch. Jetzt zählt
  Mojangs `metadata.model`, und der Ärmel-Overlay liegt beidseitig gleich auf.
- **Cosmetics sind sofort da:** Die Cosmetics-Mod wird mit dem Launcher
  ausgeliefert und automatisch in jede 26.3-Fabric-Instanz gelegt, die nicht
  ausgeschlossen ist. Bisher lagen nur die Pakete in `bamboo/cosmetics`, im
  Spiel hat sie niemand geladen. Eine selbst installierte Cosmiq-Fassung
  gewinnt und bleibt unangetastet.
- **Cosmetics-Mod braucht Fabric API:** Die Mod hängt von Fabric API ab. Der
  Launcher setzt sie deshalb nur in Instanzen ein, in denen Fabric API liegt –
  sonst hätte Fabric den Start mit einem Ladefehler quittiert.

## Neu

- **Vorschaubilder für alle Cosmetics:** Bamboo Sticks, Furry Ears, Furry Tail
  und Strohhut haben jetzt ein eigenes Bild im Shop und in der Bibliothek. Die
  Bilder liegen im Launcher und funktionieren auch ohne Katalog vom Server.
- **Instanz-Doktor:** In den Instanz-Einstellungen steht ein kurzer Bericht:
  fehlende Basisversion, Mods ohne Loader, fehlende Fabric API, doppelte Mods,
  Cosmetics-Mod nicht vorhanden und Resourcepacks, die im Ordner liegen, aber
  nicht ausgewählt sind. Was der Launcher selbst beheben kann – etwa die
  Pack-Auswahl – lässt sich mit einem Klick nachholen.
- **Cosmetics-Status pro Instanz:** Die Cosmetics-Ansicht sagt für jede
  Instanz, ob die Mod aktiv ist, beim nächsten Start eingesetzt wird, an
  fehlender Fabric API scheitert oder weil die Instanz ausgeschlossen ist.

Damit sich ein Release nachprüfen lässt, prüft `scripts/verify-release.mjs`
Feed, Download-URLs, Updater-Signaturen und auf Wunsch jede Prüfsumme; der
Release-Workflow ruft es nach dem Hochladen selbst auf.

## Entfernt

- **Bamboo Client:** Der Schalter in der Sidebar, die Client-Module und die
  mitgelieferten Client-Jars sind weg. Der Launcher ist wieder das, was er sein
  soll: Instanzen, Mods, Server und Bamboo Cosmetics.

Vollständige Liste: `ui/CHANGELOG.md`.

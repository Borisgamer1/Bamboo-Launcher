# Bundled fonts

## Monocraft

- **File:** `src/assets/fonts/Monocraft.ttf`
- **Upstream:** <https://github.com/IdreesInc/Monocraft>
- **Version:** v4.2.1, downloaded from `dist/Monocraft-ttf/Monocraft.ttf`
- **SHA-256:** `262e31822e0a75be567b02320bfa092143d871e8a273e529d1c5ab0c04cd215f`
- **License:** SIL Open Font License 1.1; the complete license text is in
  [`Monocraft-OFL.txt`](./Monocraft-OFL.txt).
- **Runtime:** bundled locally by Vite; there is no CDN or network request for the font.
- **Note:** Monocraft is a fan project based on the typeface used in the Minecraft UI. It is
  not affiliated with Mojang or Microsoft and contains no original Minecraft font assets.

The font is only referenced by the launcher's `Minecraft-Stil` option. The default launcher
font stays Inter, and the pixel font is not preloaded for users who keep the default.
